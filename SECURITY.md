# Security Policy

This project is cryptocurrency futures trading software.

**Never commit exchange API keys, API secrets, Telegram bot tokens, passwords, private configuration files, or personal trading logs.**

Use API keys with the minimum permissions required. Prefer demo/testnet accounts while developing and testing.

## Trading risk

This software is provided for development, testing, research and educational purposes. It is not financial advice and does not guarantee profits. Futures and leverage can result in rapid losses.

## Reporting security issues

Do not publish sensitive security details in a public issue. Use GitHub's private vulnerability reporting/contact mechanism if enabled for this repository.
