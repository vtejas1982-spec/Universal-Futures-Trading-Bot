# R6.8.28 Release Notes

Date: 2026-10-01

## Focus
Memory-first hardening for long-running deployment on a low-RAM Linux/Oracle VPS.

## Added
- Linux `VmRSS` process measurement from `/proc/self/status`.
- `/proc/self/statm` fallback.
- RSS delta tracking.
- RAM and swap diagnostics.
- Low-memory scanner-child admission guard.
- Fail-closed behavior when memory telemetry cannot be obtained.
- Single authoritative 60-second Hub memory diagnostic.

## Preserved
- Two-stage scanner.
- Sequential temporary preflight children.
- Scanner global position admission.
- Capital allocation authority.
- Selected timeframe authority.
- Existing AI evidence/cost/liquidation/execution/protection pipeline.
- Explicit scanner-child resource cleanup.

## Validation
Static validation and Windows/Bybit DEMO startup/scanner discovery passed. Long-run Linux VPS validation remains pending and is intentionally not represented as complete until the planned VPS run is finished.

## Known final validation
Run the bot on the approximately 1 GB Oracle VPS for several hours and inspect:
- RSS stability
- available RAM
- swap growth
- scanner child count
- UI queue size
- RSSDelta60s
- low-memory guard events
