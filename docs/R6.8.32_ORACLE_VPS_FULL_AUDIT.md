## Operational limitation
A ~1 GB VPS has little headroom. The code correctly refuses additional scanner-child admission under memory pressure, but memory admission does not proactively terminate healthy active positions. Therefore sustained multi-position operation can still exhaust a very small VPS if several active child processes accumulate memory. This is an operational capacity constraint, not a discovered R6.8.32 code defect.
