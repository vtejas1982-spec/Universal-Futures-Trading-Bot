`UniversalFuturesBot_CRYPTO_AI_AGENT_R6.8.7.2.1.py`

## Findings and fixes

### Fixed — post-fill execution drift gap
The engine already checked projected spread/slippage/depth and then checked actual fill slippage. The audit identified that actual fill distance from the strategy reference candle was not rechecked. The release now records the signal reference price and rejects a materially bad actual fill when it exceeds the configured candle-drift envelope.

### Fixed — execution-gate audit transparency
Historical candle data cannot reproduce a live order-book snapshot. The startup tradeability audit now explicitly reports the execution-quality gate as a runtime-only hard gate instead of implying that the candle-history likelihood includes spread, depth and live slippage.

### Preserved — AI trailing stop
The existing bounded AI ATR trailing engine is active after TP1/break-even processing. It only tightens the current SL, verifies the replacement before cancelling the old SL, and rechecks liquidation safety.
