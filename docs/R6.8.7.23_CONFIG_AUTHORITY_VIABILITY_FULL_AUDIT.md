1. Execution-profile diagnostics now distinguish a UI/config update from the effective runtime profile.
2. Startup emits an explicit effective execution-policy snapshot with spread, slippage, depth, drift and authority.
3. ATR diagnostics now expose configured minimum, effective minimum, and the AI-adaptive source when the effective threshold is lowered.
4. Tradeability audit retains the existing CAN TRADE authorization semantics and adds CONFIGURATION VIABILITY:
   - HEALTHY
   - CONDITIONAL
   - STATIC_INCOMPATIBLE
5. Cost-block diagnostics no longer casually recommend disabling the cost safety gate. They point to higher timeframe, valid wider structure-based protection/targets, or another setup/instrument.
6. AI provenance wording distinguishes stale-claim repair from the total audited decision-field mismatch count.
7. Divergence diagnostics explicitly report configured ON versus effective DISABLED when no source indicators are available.
8. Fixed an adaptive-ATR diagnostic f-string variable mismatch so the one-time adaptive-threshold log uses the actual quantile and floor variables.
